# 嶺先官網 · 照片拼字版

2026-09-10

## 預覽

直接用瀏覽器開啟本目錄的 `index.html`。請保留 `assets/`、`design.css` 和 `interactions.js` 的相對位置。本版不依賴 CDN、套件安裝或建置程序。

本機伺服器亦可使用：`python3 -m http.server 8765 --bind 127.0.0.1`，再開啟 `http://127.0.0.1:8765`。

## 這次改版

- 首屏以 24 張現有項目照片與主視覺拼成「嶺先」，字形已轉為透明 WebP，不依賴訪客字體載入。
- 字樣新增三層下拖陰影，並以 12 秒週期平滑上下漂浮；提供暫停／播放按鈕，滑入選圖或離開視窗時暫停，減少動態模式停用。
- 桌面游標滑過字樣中的照片時，顯示跟隨游標的完整照片卡；圖片維持自然比例、不裁切，並標示活動／項目名稱、日期或項目期間。不顯示地點，作品正文原有的地點資料不受影響。
- 命中資料由實際拼圖排列與字形透明遮罩生成；游標移至字形空隙不會誤觸其他照片。
- 名稱及資料沿用原作品內容；原資料僅有製作期間時，標籤為「項目期間」，不冒充活動當日。未提供的日期顯示「待確認」。
- 「查看拼圖作品／下一張作品／關閉」支援觸控與鍵盤，觸控裝置亦可點選字樣中的照片。Escape、頁面捲動或點擊其他區域會關閉預覽。
- 全頁共用固定的幾何背景，低對比橢圓軌跡、圓形與斜線從 Hero 延續至關於、業務、作品及頁尾；游標附近的線條局部亮起，同時帶出柔和光暈與陰影。背景不攔截操作，文字與圖片位於背景上方。
- 減少動態效果偏好啟用時，背景光影不追蹤游標，照片卡改以固定位置展示；手機保留靜態幾何背景。
- 銀白、石墨灰與系統無襯線字體；磨砂限定用於導航及 Hero，作品區保持清晰。
- 保留七項業務、VOGUE、聯絡資料與外部連結；作品增為五個分類、十二個項目。新設「有戲」AI 劇本創作 APP，並於影片製作分類加入付費課程製作服務。
- 作品画廊改為左右錯落的單列輕堆疊，單數圖片不再有空格；完整保留圖片比例。滑過卡片上浮約 7px，其他內容略暗。點擊開啟原生 dialog 燈箱，可用按鈕／方向鍵換圖、Escape／關閉按鈕退出並恢復焦點。
- 40 個來源圖片素材轉為 WebP，內容圖片延遲載入並補上固有尺寸；Hero 約 182 KB，網站約 5.3 MB。
- 《轉來》The Way Back 為 AI 短片，依使用者提供資料標示「入圍灣區國際 AI 影展最佳學生電影」，不改寫成得獎；完整劇情轉為繁體分段展示。圖集依序為海報、劇照 1、劇照 2、劇照 3。
- 「有戲」以 AI 協助靈感速記、劇本專案與分場創作，並展示三個 Android 介面；付費課程製作涵蓋文稿策劃至影片交付，示例包括西方童謠與中國古詩課程畫面。
